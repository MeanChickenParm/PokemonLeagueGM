# Pokémon League GM

A web-based Pokémon trainer management game in the style of Basketball GM. You manage trainers through a season (8 gyms, the Elite Four and the Champion), and each season's results shape the world for the next.

**Play:** https://meanchickenparm.github.io/PokemonLeagueGM/ (or download `Pokémon League GM.html` and open it in a browser).

**Build from source:** `python3 game/build.py game dist` makes the single-file game, the itch.io zip and a Node test bundle in `dist/`.

See `CLAUDE.md` for how the source is laid out and how changes are made. Old builds are kept in `archive/`.
